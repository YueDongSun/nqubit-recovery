================================================================================
MATLAB to Python Conversion Reference - AWG5014C Control
================================================================================

This document shows how to convert MATLAB AWG control code to Python.

================================================================================
DEPENDENCIES
================================================================================

Install required Python packages:

    pip install pyvisa numpy

For camera control, you may also need (depending on your camera):
    pip install opencv-python          # For generic cameras
    pip install pypylon                # For Basler cameras
    pip install ids-peak               # For IDS cameras

================================================================================
BASIC CONNECTION
================================================================================

MATLAB:
-------
visa_address = 'TCPIP::192.168.42.223::INSTR';
awg = visa('tek',visa_address,'InputBufferSize',buffer,'OutputBufferSize',buffer);
fopen(awg);

Python:
-------
import pyvisa

rm = pyvisa.ResourceManager()
awg = rm.open_resource('TCPIP::192.168.42.223::INSTR')
awg.write_termination = ';'
awg.read_termination = '\n'

# Or use the provided class:
from awg5014c_controller import AWG5014CController

with AWG5014CController('TCPIP::192.168.42.223::INSTR') as awg:
    # Use awg here
    pass

================================================================================
WAVEFORM GENERATION
================================================================================

MATLAB:
-------
samples = 1000;
t = 0:step:cycles-step;
y = single(amplitude * sin(harmonic * t));
gen_wave(y, samples)

Python:
-------
import numpy as np

samples = 1000
t = np.arange(0, cycles, step)
y = amplitude * np.sin(harmonic * t)
y = y.astype(np.float32)
awg.gen_wave(y, samples)  # Using the class

================================================================================
BINARY DATA HANDLING
================================================================================

MATLAB:
-------
binblock = zeros(1,samples*5,'uint8');
for k=1:samples
    binblock((k-1)*5+1:(k-1)*5+5) = [typecast(y(k),'uint8') m(k)];
end

Python:
-------
binblock = np.zeros(samples * 5, dtype=np.uint8)
for k in range(samples):
    y_bytes = np.frombuffer(np.float32(y[k]).tobytes(), dtype=np.uint8)
    binblock[k*5:k*5+4] = y_bytes
    binblock[k*5+4] = m[k]

================================================================================
FUNCTION DEFINITIONS
================================================================================

MATLAB:
-------
function result = myfunc(x, y)
    result = x + y;
end

Python:
-------
def myfunc(x, y):
    return x + y

With type hints:
def myfunc(x: float, y: float) -> float:
    return x + y

================================================================================
FUNCTIONS WITH CALLBACKS (Nested Functions)
================================================================================

MATLAB:
-------
function outer(x)
    function inner(y)
        disp(x + y);
    end
    inner(1);
end

Python:
-------
def outer(x):
    def inner(y):
        print(x + y)
    inner(1)

Or using lambda:
def outer(x):
    inner = lambda y: print(x + y)
    inner(1)

================================================================================
KEY DIFFERENCES TO REMEMBER
================================================================================

1. INDEXING:
   - MATLAB: 1-based indexing, A(1) is first element
   - Python: 0-based indexing, A[0] is first element

2. ARRAY SLICING:
   - MATLAB: A(1:5) gives elements 1,2,3,4,5
   - Python: A[0:5] gives elements 0,1,2,3,4 (end is exclusive)

3. MATRIX MULTIPLICATION:
   - MATLAB: A * B (element-wise with .*)
   - Python: A @ B (matrix), A * B (element-wise for numpy arrays)

4. TRANSPOSE:
   - MATLAB: A'
   - Python: A.T or np.transpose(A)

5. COMPLEX NUMBERS:
   - MATLAB: 1+2j or 1+2i
   - Python: 1+2j

6. EMPTY ARRAY:
   - MATLAB: []
   - Python: [] or np.array([])

7. INFINITY/NaN:
   - MATLAB: Inf, NaN
   - Python: np.inf, np.nan

8. LOGICAL INDEXING:
   - MATLAB: A(A > 0) = 0
   - Python: A[A > 0] = 0

================================================================================
TESTING CONNECTION
================================================================================

To test if the AWG is reachable:

Python:
-------
import pyvisa

rm = pyvisa.ResourceManager()
print("Available VISA resources:", rm.list_resources())

try:
    awg = rm.open_resource('TCPIP::192.168.42.223::INSTR')
    print("Device IDN:", awg.query('*IDN?'))
    awg.close()
except Exception as e:
    print(f"Connection error: {e}")

================================================================================
EXAMPLE: COMPLETE WORKFLOW
================================================================================

MATLAB workflow converted to Python:

# MATLAB:
# ------
# harmonic = 93;
# amplitude = 1.0;
# samples = 1000;
# cycles = 2;
# step = (2 * pi) / samples;
# cycles = cycles * 2 * pi;
# t = 0:step:cycles-step;
# y = single(amplitude * sin(harmonic * t));
# gen_wave(y, samples)

# Python:
# ------
import numpy as np
from awg5014c_controller import AWG5014CController, sine_wave

with AWG5014CController('TCPIP::192.168.42.223::INSTR') as awg:
    sine_wave(awg, harmonic=93, amplitude=1.0, samples=1000, cycles=2, channel=1)
